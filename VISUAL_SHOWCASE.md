## 📱 Responsive Behavior

### Mobile (375px - 640px)
- Single column layouts
- Smaller text sizes (text-4xl → text-5xl)
- Reduced padding (p-6 vs p-10)
- Stacked cards
- Full-width buttons

### Tablet (641px - 1024px)
- 2-column grids
- Medium text sizes (text-5xl)
- Better spacing (p-8)
- Side-by-side layouts

### Desktop (1025px+)
- 3-column grids
- Large text (text-6xl - text-8xl)
- Generous spacing (p-10 - p-12)
- Alternating layouts
- Full visual impact

## 🎨 Animation States

### Hover States
- **Scale**: `hover:scale-105` (buttons, cards)
- **Lift**: `hover:-translate-y-1` or `hover:-translate-y-2`
- **Border glow**: `border-white/10` → `hover:border-white/20`
- **Gradient overlay**: `opacity-0` → `group-hover:opacity-5`
- **Icon movement**: `group-hover:translate-x-1`

### Focus States
- **Ring**: `focus:ring-2 focus:ring-cyan-500/50`
- **Border**: `focus:border-cyan-500/50`
- **Outline**: Always visible for accessibility

### Loading States
- **Pulse**: Animated dot on "Available" badge
- **Spin**: Gradient rotation on orbs
- **Bounce**: Scroll indicator

## ✨ Special Effects

### 1. Animated Gradient Orbs
- 3 orbs per section (cyan, purple, pink)
- `animate-pulse` with different delays
- `blur-3xl` filter
- `opacity-10` for subtlety

### 2. Grid Background
- CSS linear gradients
- 4rem × 4rem spacing
- white/5 opacity
- Subtle depth

### 3. Glassmorphism
- `backdrop-blur-xl` for frosted glass
- `bg-white/5` for tint
- `border-white/10` for definition
- Multiple layers for depth
